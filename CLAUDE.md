# UI/UX Perfection & Responsive Design Requirements

Work like an elite senior UI/UX designer and expert Flutter developer. The entire MedNu and MedNu Doctor apps must look premium, modern, clean, and perfectly responsive on all screen sizes.

# Important Restriction
DO NOT modify or redesign the MedNu app Home Screen because it is already completed and finalized.

You may optimize bugs or responsiveness there only if absolutely necessary, but do not change the overall UI/UX design of the MedNu home page.

# UI Quality Expectations
Every screen in both apps must:
- Look polished and production-ready
- Have proper spacing and alignment
- Use consistent padding and margins
- Maintain proper typography hierarchy
- Have balanced line heights and text spacing
- Use proper font sizes for all devices
- Avoid cluttered layouts
- Follow modern medical app UI standards

# Responsiveness Requirements
Ensure:
- No pixel overflow errors
- No RenderFlex overflow
- No clipped widgets
- No broken layouts on small screens
- No text cutoff issues
- No overlapping UI elements
- No improper scaling issues

The apps must work perfectly on:
- Small Android devices
- Large Android devices
- Tablets
- iPhones
- Different aspect ratios

# Layout Improvements
Fix and optimize:
- Line gaps
- Widget spacing
- Button sizes
- Card padding
- Input field sizing
- App bars
- Bottom navigation
- List item spacing
- Grid layouts
- Scroll behavior
- Keyboard opening issues
- Safe area handling

# Flutter Best Practices
Use:
- Responsive layout techniques
- Flexible/Expanded properly
- MediaQuery/LayoutBuilder where needed
- Reusable UI components
- Consistent design system
- Adaptive sizing
- Proper constraints handling

# Design Style
Target a:
- Premium healthcare app feel
- Minimal and elegant interface
- Smooth animations
- Clean cards and sections
- Soft shadows and balanced spacing
- Modern form design
- Professional dashboard appearance

# UX Improvements
Improve:
- User flow
- Navigation clarity
- Empty states
- Loading states
- Error states
- Form usability
- Touch targets
- Accessibility
- Visual feedback

# Performance + UI
Optimize UI rendering to avoid:
- Janky scrolling
- Laggy animations
- Excess rebuilds
- Heavy layouts
- Slow transitions

Every page in MedNu and MedNu Doctor should feel professionally designed, visually balanced, smooth, responsive, and pixel-perfect.
